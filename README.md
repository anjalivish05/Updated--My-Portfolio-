# 🌸 Personal Portfolio Website

This is my personal portfolio website created using **HTML and CSS**.  
It showcases my introduction, skills, and contact information in a clean and responsive layout.

---

## 👩‍💻 About Me

I am a passionate beginner web developer who loves creating simple, clean, and user-friendly websites.  
I am currently learning **HTML, CSS, and basic JavaScript** and continuously improving my skills by building projects.

---

## ✨ Features

- Clean and simple UI design  
- About Me section with profile image  
- Skills section listing technical and soft skills  
- Contact form for user interaction  
- Hover effects on buttons and navigation  
- Responsive design for mobile screens  
- Uses CSS Flexbox for layout  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Media Queries  

---

## 📱 Responsive Design

The website is fully responsive and adapts to different screen sizes such as:
- Desktop  
- Tablet  
- Mobile
